# Claire 初天舒 · Works Portfolio

个人作品集，静态 HTML、CSS、JavaScript 实现。

## 本地预览

```sh
python3 -m http.server 8767
```

打开 http://localhost:8767/ 。手机尺寸预览为 `/mobile-preview.html`。

## 修改

- `index.html`：页面文字、导航和部分交互
- `assets/css/`：样式
- `assets/js/`：动画、图集和视频交互
- `assets/images/`、`assets/videos/`：图片和视频
- `assets/svg/favicon.svg`：标签页图标

## 部署

GitHub Pages 从 `main` 分支根目录发布，`.nojekyll` 保留静态文件。
视频为上线优化版本，完整原始素材另存于本地归档。
